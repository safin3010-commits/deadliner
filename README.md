# ДедЛайнер 🤖

> Telegram-бот для студентов ТюмГУ + Нетология.
> Следит за дедлайнами, расписанием и оценками — не даёт лениться.

## Что умеет

- 🌅 Утренний / дневной / вечерний брифинг с погодой, расписанием и дедлайнами
- 📚 Синхронизация заданий из LMS ТюмГУ и Нетологии (с датой и без)
- 🎓 Оценки из Modeus и LMS — уведомление при появлении новой или изменении
- 📧 Уведомления о письмах (Яндекс Почта)
- 💬 Уведомления из Яндекс Мессенджера
- 📢 Мониторинг беседы ВКонтакте
- 🔔 Напоминания — разовые, по интервалу и «каждый день»; дублируются звуком, Mac-уведомлением и записью в системные «Напоминания»
- 🇬🇧 Английский — разговорная фраза дня, паттерн произношения, диалог (все с переводом)
- 🧠 IT-теория по темам: новая тема → практика по ней → повторение через пару дней
- 🤖 AI-анализ учёбы и мотивация через Groq
- 📝 `/quiz` — парсинг вопросов тестов LMS во время прохождения в Chrome
- 📄 Экспорт конспектов курсов Нетологии в текстовые файлы — для разбора темы через другой ИИ (см. ниже)

## Расписание уведомлений

Все брифинги, английский, IT-теория, цитаты и недельный отчёт (старое расписание 9:00–22:00)
**отключены в коде** (`scheduler.py`, job'ы закомментированы) — их роль теперь выполняет
отдельный наставник-агент, см. ниже. Функции оставлены в файле нетронутыми на случай, если
захочется вернуть их как есть.

То, что реально работает внутри процесса бота (`scheduler.py: setup_scheduler`) — только
фоновые проверки источников и доставка уже поставленных пользователем задач/напоминаний:

| Job | Интервал |
|-----|----------|
| ВКонтакте (мониторинг беседы) | каждые 30 мин |
| Оценки Modeus | каждые 20 мин |
| Оценки LMS | каждые 30 мин |
| Яндекс Почта | каждые 15 мин |
| Gmail (второй ящик) | каждые 15 мин |
| Яндекс Мессенджер | каждые 15 мин |
| Уведомления Нетологии (координаторы, анонсы) | каждые 30 мин |
| Синхронизация заданий LMS + Нетология | каждые 60 мин |
| Кэш расписания (тихое обновление, без Telegram) | каждые 4 часа |
| Полный ночной обход Мессенджера (контекст для наставника, ничего не шлёт) | раз в сутки, 00:00 |
| Повтор неотправленных уведомлений | каждые 10 мин |
| Пользовательские напоминания и задачи | каждые 3 мин |

Напоминание про звонок/пару через ~15 минут (`check_lesson_reminders`) и проверка дедлайнов
за 7/3/1 день (`check_deadline_reminders`) — рабочий код, но не подключены к планировщику.

### Наставник — отдельный процесс, вне бота

Параллельно с ботом, независимо от того, запущен ли он, работает вторая система — «наставник»,
на `launchd` (`~/Library/LaunchAgents/com.ilnursafin.*`). Она не трогает и не перезапускает бота,
читает те же `data/*.json` и пишет в Telegram напрямую через Bot API. AI-часть — headless
`claude -p` (только чтение, без Bash), через подписку Claude Code, без отдельного API-ключа.

- **Чек-ины** ([scripts/mentor_checkin.py](scripts/mentor_checkin.py)) — задуманы как 6 слотов
  в день (08:30, 10:31, 13:31, 15:32, 18:32, 20:33), каждый со своим фокусом (утро/лёгкий пинг/
  расписание/мотивация/итог дня/на сон, воскресенье вечером — недельный итог). **Фактически
  launchd-plist сейчас настроен только на 3 срабатывания — 08:30, 14:00, 20:33** — то есть
  слоты «лёгкий пинг», «мотивация» и «итог дня» почти никогда не выбираются (в 14:00 код
  подбирает ближайший по времени слот и попадает на «расписание», а не на задуманный слот).
- **Контекст вместо памяти сессии** ([scripts/mentor_context.py](scripts/mentor_context.py)) —
  код собирает для каждого вызова Claude компактную сводку (расписание, дедлайны,
  просрочки, напоминания, обещания, почта за сутки, найденное поиском). Claude получает
  только её, без инструментов и без `--resume` дневной сессии: ~20 тыс. токенов на чек-ин
  вместо 0,3–1,3 млн раньше. Расход каждого вызова — в `data/agent_calls.jsonl` (`/tokens`).
- **Память агента** ([agent_db.py](agent_db.py), `data/agent.db`, SQLite) — неизменяемый журнал
  входящего (почта, мессенджер, ВК, уведомления Нетологии, оценки, новые задачи, твои
  сообщения боту) с полнотекстовым поиском, оргфакты вебинаров для поиска, обещания,
  диалог с ботом. История больше не теряется в скользящих `*_recent.json`.
- **Обещания** — скажи боту «сделаю лабу в воскресенье», он предложит записать (только по
  кнопке); открытые видны в чек-инах и в `/promises`.
- **Триггеры «писать или молчать»** ([scripts/agent_triggers.py](scripts/agent_triggers.py)) —
  пока в теневом режиме: считают поводы (низкая оценка, дедлайн ≤ 48 ч, просроченное
  обещание, перенос пары) и решение, пишут в журнал, ничего не отправляют.
  `venv/bin/python3 scripts/agent_triggers.py report` — посмотреть.
- **Почасовой сторож** ([scripts/mentor_hourly_watch.py](scripts/mentor_hourly_watch.py)) —
  раз в 2 часа (`StartInterval=7200`): ссылки на вебинары, баллы/посещаемость раз в сутки,
  разбор объявлений ВК о переносах, поиск по оргфактам, теневые триггеры.
- **Окно на столе** ([scripts/native_widget](scripts/native_widget), Swift/WebKit) — правая половина
  экрана MacBook, списки строит код ([scripts/mentor_dashboard.py](scripts/mentor_dashboard.py)),
  без Claude: расписание сегодня/завтра, напоминания, дедлайны на 3 дня, просрочки, цитата.
  Галочки «сделано» (двойное нажатие + 5 с на отмену + «↩️ Вернуть» в Telegram), кнопка
  «Обновить». Сборка: `swiftc -O main.swift -o MentorWidget`, plist — шаблон рядом.
- **Q&A** ([mentor_qa.py](mentor_qa.py) + [scripts/raycast_commands/ask_mentor.sh](scripts/raycast_commands/ask_mentor.sh)) —
  вопрос наставнику прямо с Mac через Raycast, без Telegram.
- **Сторож ошибок** ([scripts/error_watchdog.py](scripts/error_watchdog.py)) — раз в 15 минут
  смотрит новый кусок `bot.log`; для узкого списка известных багов (бот не жив, протухший путь
  к venv) автоматически перезапускает бота через `stop.sh`/`start.sh`, для прочих сбоев (LMS 403,
  Modeus SSO и т.п.) шлёт одно предупреждение в Telegram без спама повторами.

Тихий старт: первые 2 минуты после запуска бот только запоминает текущее состояние (оценки, задания), не спамит уведомлениями о том, что «появилось» за время простоя.

## Быстрый старт

### 1. Требования

- macOS
- Python 3.13
- Google Chrome (только для `/quiz`)

### 2. Клонируй репозиторий

```bash
git clone https://github.com/safin3010-commits/deadliner.git
cd deadliner
```

### 3. Запусти установщик

```bash
python3 setup.py
```

Установщик сам спросит все нужные данные, проверит логины и пароли, создаст `.env` и установит зависимости.

### 4. Запусти бота

```bash
bash start.sh
```

Бот работает в фоне (`caffeinate` не даёт маку заснуть, пока бот жив). Терминал можно закрыть.

## Что спрашивает установщик

| Шаг | Что нужно | Где взять |
|-----|-----------|-----------|
| Имя | Как бот будет к тебе обращаться | Любое |
| Telegram токен | Токен бота | @BotFather → /newbot |
| Telegram ID | Твой ID | @userinfobot |
| Город | Для погоды и часового пояса | Вводишь название |
| Groq ключ | Для AI-функций | console.groq.com → API Keys |
| Логин utmn.ru | Для Modeus и LMS | Твои учётные данные ТюмГУ |
| Нетология | Email и пароль | Твои данные netology.ru |
| Яндекс Почта | Почта + пароль приложения | Яндекс ID → Безопасность → Пароли приложений |

## Команды бота

| Команда | Что делает |
|---------|-----------|
| `/start` | Приветствие + главное меню (клавиатура снизу) |
| `/tasks` | Список активных задач |
| `/add` | Добавить задачу вручную (диалог: название → дедлайн) |
| `/schedule` | Расписание — сегодня/неделя/следующая неделя/месяц |
| `/grades` | Оценки по предметам (список предметов → детали по нажатию) |
| `/quiz` | Начать парсинг теста LMS, открытого в Chrome |
| `/quizstop` | Остановить парсинг |
| `/analysis` | Полный AI-анализ успеваемости по всем предметам |
| `/itog <текст>` | Отчитаться что сделал за день — AI разберёт и посчитает стрик |
| `/streak` | Текущий и рекордный стрик (считается по датам закрытия задач) |
| `/promises` | Открытые обещания с кнопками «выполнено» / «снять» |
| `/tokens` | Расход Claude за сегодня и 7 дней + оценки 👍/👎 наставника |
| `/cancel` | Отменить текущий диалог (добавление задачи и т.п.) |

Кроме команд, боту можно просто писать текстом — он сам разбирает:
- новые задачи: `Сдать лабораторную до пятницы`, `Добавь на завтра: матан, физра, английский`
- напоминания: `напомни через 20 минут`, `каждый день в 9 утра пить таблетку`
- если неясно, задача это или напоминание — бот переспросит
- обещания: `сделаю лабу в воскресенье` — предложит записать и потом спросит, если срок пройдёт
- вопросы: `когда следующий вебинар по БД?` — отвечает по данным и поиску по переписке/вебинарам

## Главное меню

После `/start` бот показывает постоянную клавиатуру с тремя кнопками:

| Кнопка | Что делает |
|--------|-----------|
| 📋 Задания | Список всех активных задач; внутри — «Отметить выполненным», «Редактировать», «Удалить», «Срочные», управление напоминаниями |
| 📅 Расписание | Выбор периода: сегодня / эта неделя / следующая неделя / месяц |
| 🎓 Оценки | Список предметов с итогами → по нажатию журнал оценок и посещаемость по предмету |

### Как создать задачу

**Просто напиши боту** — он распознаёт дату и создаёт задачу сам:
- `Сдать лабораторную до пятницы`
- `Купить учебник до 30 апреля, напомни за 3 дня`
- `Каждый день на эту неделю: повторить конспекты`

Либо через `/add` — бот сам спросит название и дедлайн.

### Как создать напоминание

Напиши текстом — например «напомни завтра в 18:00 позвонить врачу» или «каждые 2 часа пить воду 5 раз». Бот через AI разбирает: дату, время, разовое/повторяющееся, интервал, количество повторов (в том числе «каждый день» как отдельный режим) — и уточняет недостающее кнопками.

### Как запустить /quiz

1. Открой LMS в Google Chrome и войди в аккаунт
2. Напиши боту `/quiz`
3. Открой нужный тест в браузере — вопросы начнут приходить автоматически
4. После окончания теста напиши `/quizstop`

> ⚠️ Quiz работает только с Google Chrome (и только если Chrome уже открыт — бот не будит его сам). Другие браузеры не поддерживаются.

### Экспорт конспектов Нетологии (для обучения через другой ИИ)

Выгружает по каждому курсу **текущего семестра** Нетологии темы занятий, даты
вебинаров, дедлайны заданий и полный текст материалов/презентаций (PDF
распознаются через pdfplumber) — в отдельные `.txt` файлы, которые удобно
скормить другому ИИ для разбора темы.

```bash
venv/bin/python3 scripts/export_netology_syllabus.py
```

Результат — в `netology_conspekty/` (в git не попадает, см. `.gitignore`):
- `00_INDEX.txt` — сводка дедлайнов и вебинаров по всем курсам
- по одному `.txt` на курс

Скрипт сам определяет «текущий семестр» по префиксу `"3 семестр:"` в названии
курса — константа `SEMESTER_PREFIX` в `scripts/export_netology_syllabus.py`.
При переходе на следующий семестр поменяй эту константу.

На 05.09.2026 у части курсов (Аналитическое чтение, Финансовое мышление,
Разработка на Java, Дискретная математика, Иностранный язык) на площадке ещё
не было материалов — по мере публикации просто перезапусти скрипт, он
пересоберёт всё заново поверх старых файлов.

## Проблемы

**Бот не запускается**
```bash
tail -50 bot.log
```

**Расписание не работает**
Проверь `MODEUS_USERNAME` и `MODEUS_PASSWORD` в `.env`

**Оценки не приходят**
Проверь `LMS_USERNAME/PASSWORD` и `MODEUS_USERNAME/PASSWORD` в `.env`

**AI не отвечает**
Проверь `GROQ_KEY_1` на [console.groq.com](https://console.groq.com) — возможно превышен лимит

**Задания из Нетологии/LMS периодически пропадают**
Если в названии задания нестандартный формат дедлайна, парсер может его не распознать и задание не попадёт в список — это баг-класс, не «задания не выставили». Стоит сверять с сайтом, если что-то долго не появляется.

**Почта не приходит, в логе `AUTHENTICATIONFAILED` / `IMAP is disabled`**
Пароль приложения Яндекс.Почты истёк или отозван — сгенерируй новый (Яндекс ID → Безопасность → Пароли приложений) и обнови `YANDEX_APP_PASSWORD` в `.env`.

**Quiz не находит вопросы**
Убедись что залогинен в LMS через Chrome (не через другой браузер), и что Chrome уже запущен — бот не открывает его сам.

**ВК не отправляет сообщения**
Куки протухли — запусти: `venv/bin/python3 -m parsers.vk_browser --save-cookies`

**Яндекс Мессенджер не работает**
Запусти установщик заново: `python3 setup.py` и перенастрой мессенджер

## Стек

- Python 3.13, python-telegram-bot, APScheduler
- Groq API (llama-3.3-70b-versatile) — бесплатно, единственный подключённый AI-провайдер (ключи `OPENROUTER_KEY_*` в `.env.example` пока не используются кодом)
- Open-Meteo — погода, фолбэк без ключа; основной источник — парсинг Яндекс.Погоды через Playwright
- Playwright — ВК, Яндекс Мессенджер, погода
- httpx — LMS, Нетология, Modeus (логин по логину/паролю, без браузера)
- pdfplumber, BeautifulSoup — экспорт конспектов Нетологии
