## Проблемы
1. Токены: утренний чек-ин тратит 0,3–1,3 млн токенов (до 27 обращений к инструментам Read + пересылка всей дневной сессии). В день набегает 1–3 млн.
2. Память фрагментирована: письма и чаты хранятся скользящим окном и теряются; нет истории по предметам; нет учёта моих обещаний («сделаю лабу в пятницу»); нет дневника.
3. Агент пишет по расписанию, а не по поводу; не замечает «письмо преподавателя ждёт ответа», «обещание просрочено», «оценка просела».
4. Когда LLM строила списки дедлайнов сама — путала даты (время напоминания вместо даты события), теряла пункты. Это уже вынесено в код.

## Мой план (кратко)
1. Event log в SQLite (append-only, dedup по хэшу, FTS5): все источники пишут нормализованные события + справочник курсов с алиасами.
2. Состояние (задачи, пары, оценки, посещаемость, риск по курсу) — детерминированные проекции кодом.
3. Извлечение: на каждое новое письмо/сообщение — дешёвый вызов Haiku с JSON-схемой (нужен ли ответ, срок, факты курса, обещания, важность).
4. Память слоями: profile.md, commitments (обещания), diary (сжатые дни/недели), course_notes, knowledge с поиском, последние 10–20 реплик диалога.
5. Вместо `--resume` дневной сессии — context pack ≤ 8–12 тыс. токенов, собранный кодом под конкретный повод.
6. Триггеры по поводу со скорингом важности (новая оценка, риск дедлайна, просроченное обещание, письмо ждёт ответа, перенос пары) + тихие часы + дневной бюджет токенов; плановыми остаются только утренний бриф и вечерний итог.
7. Инструменты для модели (MCP-сервер или CLI) вместо Read по файлам: get_today, get_course_status, search_knowledge, search_history, list_commitments, propose_task/propose_reminder (запись только после подтверждения кнопкой).
8. Рефлексия: ночью Haiku пишет дневник и обновляет обещания; в воскресенье Sonnet делает недельный разбор и правит профиль и заметки курсов.
Цель по бюджету: ~60–120 тыс. токенов в день вместо 1–3 млн.

Жёсткие правила проекта: списки и даты строит код, не LLM; запись в данные только кодом и с подтверждением; занятия Modeus и Нетологии — разные, не дедуплицировать; напоминание исчезает только когда я сам его закрыл; дата события ≠ время напоминания.
